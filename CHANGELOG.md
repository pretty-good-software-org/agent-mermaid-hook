# Changelog

All notable changes to this project will be documented in this file.

## [v0.3.1] - 2026-09-15

### Fixed

- The version command reports the release version; v0.3.0 reported 0.2.0. Releases now write the version into
  package.json when the changelog is batched

## [v0.3.0] - 2026-09-15

### Changed

- Renamed to agent-mermaid-hook: binary, package, release archives, state directory and the width variable
  AGENT_MERMAID_MAX_WIDTH (was CLAUDE_MERMAID_MAX_WIDTH)

## [v0.2.0] - 2026-09-15

### Added

- display command for the MessageDisplay hook: fenced Mermaid is replaced by its drawing in place while the reply
  streams, with open fences held across chunks

### Changed

- session-start context says diagrams are shown in place of the source

### Removed

- The Stop hook command; Claude Code 2.1.152 or newer is required

## [v0.1.0] - 2026-09-14

### Added

- Stop and SessionStart hooks that draw fenced Mermaid blocks as Unicode box art under each Claude Code reply
